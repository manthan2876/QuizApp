# QuizApp

A browser-based quiz built with React and Vite. The app presents a start screen, multiple-choice question cards, immediate feedback on answers, a per-question timer, and a final results summary.

## Features

- Start screen with quiz details
- Multiple-choice questions displayed as cards
- Instant answer feedback with green/red button states
- Correct answer revealed after each selection
- Score increments for correct answers
- Timeout penalty: unanswered question skips forward and removes one point
- Final score page with review of all results

## Run locally

1. Open a terminal in the `QuizApp` folder.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the listed local URL in your browser.

## Build

```bash
npm run build
```
